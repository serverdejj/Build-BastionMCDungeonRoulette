# Comandos V3

- `/droulette remove`: mira al bloque registrado y ejecuta el comando como OP. Se borra únicamente su registro en `plugins/BastionMCDungeonRoulette/config.yml`; el bloque físico no se rompe. No permite eliminar una ruleta mientras gira.
- `/droulette set facil|normal|dificil`: sigue funcionando como antes.
- Las ubicaciones actuales se conservan: NO borres `blocks` de tu configuración de Holy Hosting.
- Los nuevos mensajes `admin-remove*` son opcionales y se pueden añadir al `config.yml` del servidor.
